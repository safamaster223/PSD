# 3.2 Penanganan Outlier

Dokumen ini memuat prosedur deteksi dan penanganan nilai pencilan (*outlier handling*) pada data deret waktu polutan atmosfer di **Kecamatan Wonoayu, Kabupaten Sidoarjo** (periode **31 Agustus 2025 s.d. 31 Agustus 2026**).

---

## 1. Metodologi Deteksi Outlier Sesuai Panduan Tugas

Sesuai dengan standarisasi pengerjaan **Tugas 3 Preprocessing Sebelum Ekstraksi Fitur**, urutan tahapan yang disepakati adalah:
1. **Deteksi Pencilan Terlebih Dahulu (*Outlier Detection*)**:  
   Menggunakan metode *Interquartile Range* (IQR) dengan faktor pengali $1.5$.
2. **Konversi Outlier Menjadi Nilai Kosong (`NaN`)**:  
   Setiap titik observasi yang melampaui batas pagar bawah (*lower bound*) atau pagar atas (*upper bound*) diubah menjadi `np.nan` agar dapat diimputasi secara seragam bersama *missing value* bawaan pada tahap berikutnya (**3.3 Imputasi Missing Value**).

---

## 2. Formulasi Matematis Batas Pagar IQR

Untuk parameter polutan target **$\text{NO}_2$**:

1. **Kuartil 1 ($Q_1$) & Kuartil 3 ($Q_3$)**:
   Persentil ke-25 dan persentil ke-75 dari konsentrasi $\text{NO}_2$.
2. **Rentang Antarkuartil ($\text{IQR}$)**:
   $$\text{IQR} = Q_3 - Q_1$$
3. **Batas Bawah (*Lower Bound*)**:
   $$\text{Lower Bound} = Q_1 - 1.5 \times \text{IQR}$$
4. **Batas Atas (*Upper Bound*)**:
   $$\text{Upper Bound} = Q_3 + 1.5 \times \text{IQR}$$

---

## 3. Implementasi Kode Penanganan Outlier

```python
import pandas as pd
import numpy as np

# 1. Membaca data deret waktu hasil pengumpulan
csv_path = "data/downloads/wonoayu_pollutants_data/wonoayu_NO2.csv"
df = pd.read_csv(csv_path)
df['date'] = pd.to_datetime(df['date'])
df = df.sort_values('date').reset_index(drop=True)

target_pollutant = 'NO2'

# 2. Paksa kolom target menjadi numerik, gagal konversi -> NaN
df[target_pollutant] = pd.to_numeric(df[target_pollutant], errors='coerce')
n_missing_before = df[target_pollutant].isna().sum()
print(f"Jumlah nilai non-numerik/kosong awal: {n_missing_before}")

# 3. Hitung batas pagar IQR
Q1 = df[target_pollutant].quantile(0.25)
Q3 = df[target_pollutant].quantile(0.75)
IQR = Q3 - Q1
lower_bound = Q1 - 1.5 * IQR
upper_bound = Q3 + 1.5 * IQR

# 4. Ganti nilai di luar batas menjadi NaN
is_outlier = (df[target_pollutant] < lower_bound) | (df[target_pollutant] > upper_bound)
n_outliers = is_outlier.sum()
df.loc[is_outlier, target_pollutant] = np.nan

print(f"Jumlah outlier yang terdeteksi dan dikonversi ke NaN: {n_outliers}")
print(f"Total NaN siap diimputasi (Missing awal + Outlier): {df[target_pollutant].isna().sum()}")
```

---

## 4. Hasil dan Alur Lanjutan

Dengan mengonversi outlier menjadi `NaN`, lonjakan data ekstrem yang tidak wajar tidak akan membiaskan kurva interpolasi, dan sinyal siap direkonstruksi secara penuh pada **3.3 Imputasi Missing Value**.
