# 3.3 Imputasi Missing Value

Dokumen ini memuat prosedur imputasi data hilang (*missing value imputation*) pada deret waktu kualitas udara **Kecamatan Wonoayu, Kabupaten Sidoarjo** (periode **31 Agustus 2025 s.d. 31 Agustus 2026**).

---

## 1. Urgensi Imputasi pada Data Deret Waktu

Setelah melalui tahap **3.2 Penanganan Outlier**, dataset memiliki nilai kosong (`NaN`) yang berasal dari dua sumber:
1. **Missing Value Alami**: Nilai kosong bawaan satelit akibat tutupan awan tebal (*cloud mask*) selama musim hujan di Jawa Timur.
2. **Outlier yang Dikonversi**: Nilai pencilan ekstrem di luar pagar batas $Q_1 - 1.5\text{IQR}$ dan $Q_3 + 1.5\text{IQR}$ yang telah dikosongkan.

Untuk melakukan ekstraksi 68 fitur pada **BAB 4**, seluruh nilai kosong ini **wajib diisi penuh (100% terisi)** tanpa membuang baris kalender.

---

## 3.3.1 Interpolasi Linear Berbasis Waktu (*Time-based Interpolation*)

### A. Formulasi Matematis

Interpolasi linear menghubungkan dua titik observasi valid terdekat $(t_0, y_0)$ dan $(t_1, y_1)$ menggunakan garis linier:

$$y(t) = y_0 + (t - t_0) \cdot \frac{y_1 - y_0}{t_1 - t_0}$$

Dengan menggunakan metode waktu (`method='time'`), pembobotan interpolasi memperhitungkan selisih jarak hari sesungguhnya antar tanggal observasi.

### B. Penanganan Batas Awal dan Akhir (*Boundary Padding*)
Apabila nilai kosong berada di baris paling awal atau paling akhir rentang waktu kalender, digunakan proteksi:
*   **Forward Fill (`.ffill()`)**: Membawa nilai valid terakhir ke depan.
*   **Backward Fill (`.bfill()`)**: Membawa nilai valid pertama ke belakang.

---

## 2. Implementasi Kode Python Sesuai Standar Tugas 3

```python
import pandas as pd
import numpy as np

# Melanjutkan dari dataframe df yang telah ditandai outlier-nya:
# df.loc[(df[target_pollutant] < lower_bound) | (df[target_pollutant] > upper_bound), target_pollutant] = np.nan

# 1. Terapkan interpolasi linear berbasis indeks waktu
df_clean = df.set_index('date').interpolate(method='time').ffill().bfill()

# 2. Verifikasi keterisian nilai
n_missing_after = df_clean[target_pollutant].isna().sum()
print(f"Jumlah missing value setelah imputasi: {n_missing_after} (Wajib 0)")
print(f"Total baris waktu kontinu yang siap diekstraksi: {len(df_clean)}")

# 3. Ekstraksi sinyal 1D untuk TSFEL
fs = 1  # 1 sampel per hari
signal_1d = df_clean[target_pollutant].astype(float).values
print(f"Bentuk larik sinyal 1D: {signal_1d.shape}")
```

## 3. Hasil Rekonstruksi

Setelah proses interpolasi:
*   Seluruh baris kosong berhasil terisi secara mulus.
*   Data memiliki **366 hari observasi kontinu penuh** ($\Delta t = 1\text{ hari}$) tanpa ada jeda waktu (*zero gaps*).
*   Sinyal $1\text{D}$ siap diproses langsung ke modul ekstraksi fitur 68 TSFEL.
