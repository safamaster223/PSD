# 3.4 Validasi Data Bersih

Dokumen ini memuat prosedur pengujian mutu, validasi integritas (*Quality Assurance & Validation*), serta lampiran berkas dataset deret waktu bersih hasil prapemrosesan kualitas udara **Kecamatan Wonoayu, Kabupaten Sidoarjo** (periode **31 Agustus 2025 s.d. 31 Agustus 2026**).

---

## 1. Kriteria dan Checklist Validasi Data Bersih

Sebelum data dialirkan ke tahapan ekstraksi fitur (**BAB 4**), seluruh kriteria pengujian mutu wajib terpenuhi secara menyeluruh:

| No | Parameter Uji | Standar Kelulusan | Status Hasil |
| :-: | :--- | :--- | :---: |
| **1** | **Kelengkapan Sampel (*Zero Missing Value*)** | $\text{Missing Value} = 0$ ($100\%$ terisi dari 366 hari) | **LULUS (0 NaN)** |
| **2** | **Keteraturan Kronologis (*Monotonic Ascending*)** | Tanggal berurutan dari `2025-08-31` s.d. `2026-08-31` tanpa duplikasi atau tanggal terlewat ($\Delta t = 1\text{ hari}$) | **LULUS (366 Hari)** |
| **3** | **Batas Fisis Realistis (*Physical Plausibility*)** | Konsentrasi polutan bernilai positif non-nol ($x > 0$) dan tidak melampaui batas fisis atmosfer troposfer | **LULUS ($x > 0$)** |
| **4** | **Presisi Tipe Data (*Data Type Consistency*)** | Tipe data konsisten `Float64` untuk seluruh kolom numerik | **LULUS (Float64)** |
