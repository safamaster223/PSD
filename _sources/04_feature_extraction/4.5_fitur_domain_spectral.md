# 4.5 Fitur Domain Spectral

Dokumen ini memuat perincian 26 fitur dalam **Domain Spectral & Wavelet** dari daftar 68 fitur TSFEL yang diekstraksi untuk sinyal polutan $\text{NO}_2$ **Kecamatan Wonoayu, Kabupaten Sidoarjo**, lengkap dengan **deskripsi**, **konsep frekuensi**, dan **pembuktian kode Python menggunakan pustaka TSFEL**.

## 1. Konsep Domain Spectral

Domain spektral mentransformasikan sinyal deret waktu dari domain waktu ke domain frekuensi menggunakan Transformasi Fourier Cepat (*Fast Fourier Transform* / FFT) dan Transformasi Wavelet (*Wavelet Transform*). Fitur ini mengevaluasi sebaran energi, periodisitas tersembunyi (misal siklus mingguan atau bulanan), serta spektrum daya sinyal.

## 3. Perhitungan Konseptual & Pembuktian Kode TSFEL

Untuk domain spektral, sinyal waktu dikonversi ke spektrum frekuensi menggunakan **Fast Fourier Transform (FFT)**. Untuk sampel sinyal acuan sederhana $N=5$ dengan frekuensi sampling $fs = 1\text{ Hz}$:
$$X = [1.0, 3.0, 2.0, 5.0, 4.0]$$

### A. Konsep Perhitungan Spektral

1. **Komponen Frekuensi Nyquist**:
   - Dengan $fs = 1\text{ Hz}$ dan $N = 5$, sumbu frekuensi bernilai $f = [0.0, 0.2, 0.4]\text{ Hz}$ (sampai batas $fs/2 = 0.5\text{ Hz}$).
2. **Frekuensi Fundamental (`fundamental_frequency`)**:
   - Resolusi frekuensi dasar $\Delta f = \frac{fs}{N} = \frac{1}{5} = \mathbf{0.2\text{ Hz}}$.
3. **Frekuensi Maksimum (`max_frequency`)**:
   - Batas tertinggi komponen frekuensi signifikan $\mathbf{0.4\text{ Hz}}$.
4. **Sentroid Spektral (`spectral_centroid`)**:
   - Rata-rata frekuensi terbobot energi $\bar{f}_{\text{spec}} = \frac{\sum f_i \cdot P(f_i)}{\sum P(f_i)} \approx \mathbf{0.0946\text{ Hz}}$.

## 4. Contoh Perhitungan Manual per Fitur (26/26, Terverifikasi)

Seluruh hitungan memakai sinyal acuan $X = [1.0, 3.0, 2.0, 5.0, 4.0]$, $fs = 1$. Basis bersama (fungsi `calc_fft` TSFEL = magnitudo $|\mathrm{rfft}|$):

$$f = [0.0,\ 0.2,\ 0.4], \qquad |F| = [15.0,\ 3.6903,\ 3.3737], \qquad \sum|F| = 22.0640$$

Kumulatif: $\mathrm{cumsum}(|F|) = [15.0,\ 18.6903,\ 22.0640]$. Setiap angka di bawah **dihitung manual lalu dicocokkan** dengan output TSFEL (cocok semua).

### 4.1 Berbasis FFT langsung (17 fitur)

1. **`fundamental_frequency` = 0.2** — Kurangi mean dulu ($X - \bar{X}$, $\bar{X} = 3$), magnitudo jadi $[0.0,\ 3.6903,\ 3.3737]$. Puncak besar = yang $> 0.3 \times \max = 1.1071$, di luar indeks 0 → puncak di indeks 1 → $f_0 = f[1] = \mathbf{0.2\text{ Hz}}$.
2. **`max_frequency` = 0.4** — Ambang $0.95 \times 22.0640 = 20.9608$. Kumulatif pertama yang melewati ambang: indeks 2 ($22.0640$) → $f = \mathbf{0.4\text{ Hz}}$.
3. **`median_frequency` = 0.0** — Ambang $0.50 \times 22.0640 = 11.0320$. Kumulatif pertama yang **melebihi** ambang: indeks 0 ($15.0 > 11.032$) → $f = \mathbf{0.0\text{ Hz}}$ (energi menumpuk di DC karena mean sinyal besar).
4. **`max_power_spectrum` = 3.015028** — Khusus fitur ini TSFEL memakai **Welch** (bukan FFT langsung): sinyal dibagi std ($\sigma = 1.4142$), `scipy.signal.welch(x/\sigma, fs=1, nperseg=5)` → daya $[0.416667,\ 2.181695,\ 3.015028]$ → maksimum $= \mathbf{3.015028}$.
5. **`power_bandwidth` = 0.4** — Dari daya Welch di atas (total $5.61339$): batas bawah = frekuensi pertama yang kumulatifnya $\geq 95\%$ → $0.4$; batas atas = dari sisi kanan → $0.0$. Lebar $= |0.0 - 0.4| = \mathbf{0.4\text{ Hz}}$.
6. **`spectral_centroid` = 0.094613** — $\frac{0.0 \times 15.0 + 0.2 \times 3.6903 + 0.4 \times 3.3737}{22.0640} = \frac{0.7381 + 1.3495}{22.0640} = \frac{2.0875}{22.0640} = \mathbf{0.094613\text{ Hz}}$.
7. **`spectral_spread` = 0.149008** — $\sqrt{\frac{(0-0.094613)^2 \cdot 15.0 + (0.2-0.094613)^2 \cdot 3.6903 + (0.4-0.094613)^2 \cdot 3.3737}{22.0640}} = \sqrt{0.022204} = \mathbf{0.149008\text{ Hz}}$.
8. **`spectral_skewness` = 1.201409** — $\frac{\sum (f_i - 0.094613)^3 \cdot (|F_i|/22.0640)}{0.149008^3} = \frac{0.003975}{0.003309} = \mathbf{1.201409}$ (menceng kanan: energi menumpuk di frekuensi rendah).
9. **`spectral_kurtosis` = 2.850000** — $\frac{\sum (f_i - 0.094613)^4 \cdot (|F_i|/22.0640)}{0.149008^4} = \frac{0.001404}{0.000493} = \mathbf{2.850}$ (leptokurtik: energi terfokus).
10. **`spectral_entropy` = 0.994222** — Buang komponen DC dulu ($X - \bar{X}$), daya $= |F|^2 = [0.0,\ 13.6182,\ 11.3818]$, peluang $p = [0,\ 0.5447,\ 0.4553]$. Entropi ternormalisasi $= \frac{-(0.5447\log_2 0.5447 + 0.4553\log_2 0.4553)}{\log_2 2} = \frac{0.994222}{1} = \mathbf{0.994222}$ (hampir maksimal: energi terbagi rata di dua pita).
11. **`spectral_decrease` = −2.423971** — Pita $= |F|[1{:}] = [3.6903,\ 3.3737]$, $k = [2,\ 3]$. Pembilang $= \frac{3.6903-15.0}{2-1} + \frac{3.3737-15.0}{3-1} = -11.3097 - 5.8131 = -17.1228$. Penyebut $= 3.6903 + 3.3737 = 7.0640$. Hasil $= -17.1228 / 7.0640 = \mathbf{-2.423971}$ (energi turun tajam dari DC).
12. **`spectral_distance` = −22.658273** — Garis lurus acuan $= \mathrm{linspace}(0,\ 22.0640,\ 3) = [0.0,\ 11.0320,\ 22.0640]$. Jumlah selisih $= (0.0-15.0) + (11.0320-18.6903) + (22.0640-22.0640) = -15.0 - 7.6583 + 0 = \mathbf{-22.658273}$.
13. **`spectral_roll_off` = 0.4** — Frekuensi pertama yang kumulatifnya $\geq 95\%$ total ($20.9608$) → indeks 2 → $\mathbf{0.4\text{ Hz}}$.
14. **`spectral_roll_on` = 0.0** — Frekuensi pertama yang kumulatifnya $\geq 5\%$ total ($1.1032$) → indeks 0 ($15.0$) → $\mathbf{0.0\text{ Hz}}$.
15. **`spectral_slope` = −1.317338** — Regresi linier $|F| = m f + b$ ($n=3$): pembilang $= \frac{1}{22.0640}(3(0{\cdot}15 + 0.2{\cdot}3.6903 + 0.4{\cdot}3.3737) - 0.6 \times 22.0640) = \frac{1}{22.0640}(6.2626 - 13.2384) = -0.316161$; penyebut $= 3(0 + 0.04 + 0.16) - 0.36 = 0.24$. $m = -0.316161/0.24 = \mathbf{-1.317338}$.
16. **`spectral_variation` = 0.122125** — Korelasi silang ternormalisasi dua spektrum berurutan: $\sum_{i} m_i m_{i+1} = 15.0{\cdot}3.6903 + 3.6903{\cdot}3.3737 = 67.8037$; $\sqrt{\sum m_{i+1}^2} = 5.0$; $\sqrt{\sum m_i^2} = 15.4493$. Hasil $= 1 - 67.8037/(5.0 \times 15.4493) = 1 - 0.877875 = \mathbf{0.122125}$.
17. **`spectral_positive_turning` = 0** — Selisih magnitudo $= [3.6903-15.0,\ 3.3737-3.6903] = [-11.3097,\ -0.3165]$. Titik belok positif = pola naik-lalu-turun ($>0$ lalu $<0$): tidak ada → $\mathbf{0}$.
18. **`spectrogram_mean_coeff` = [1.020833, 3.041667, 3.520833]** — `scipy.signal.spectrogram(X, fs=1, nperseg=4)` (3 bin karena $N=5$), daya tiap bin waktu dirata-ratakan sepanjang waktu → tiga koefisien di atas (label `0.0Hz`, `0.25Hz`, `0.5Hz`).
19. **`human_range_energy` = 0.0** — Rasio energi pita $0.6$–$2.5\text{ Hz}$ terhadap total. Bin tertinggi sinyal ini $0.4\text{ Hz}$ < $0.6\text{ Hz}$ → tidak ada energi di pita manusia → $\mathbf{0.0}$.

### 4.2 Koefisien cepstral (2 fitur)

20. **`lpcc`** — Koefisien prediksi linier orde-12 (LPC) → spektrum daya koefisien → $\log$ → IFFT → 12 koefisien cepstral. **Catatan jujur:** butuh sinyal $\geq 12$ titik, sehingga **tidak dapat dijalankan pada sinyal acuan $N=5$** (TSFEL melempar error `Input signal must have a length >= n_coeff`). Pada deret NO₂ riil (366 hari) fitur ini terekstraksi normal.
21. **`mfcc`** — Alur: pre-emphasis ($0.97$) → FFT $512$ titik → 40 filter mel → $\log$ → DCT → 12 koefisien + lifter $22$. Pada sinyal acuan menghasilkan $[-31.498,\ 136.480,\ 110.209,\ \dots]$ (12 angka, terverifikasi kode). Perhitungan tangan penuh tidak praktis (ratusan operasi); yang ditunjukkan adalah alur + verifikasi kode TSFEL.

### 4.3 Wavelet — Mexican Hat / CWT, 9 skala (5 fitur)

Dekomposisi `continuous_wavelet_transform(X, wavelet="mexh", widths=1..9)` menghasilkan matriks koefisien $9 \times 5$ (skala × waktu). Perhitungan tangan penuh tidak praktis; definisi + verifikasi kode:

22. **`wavelet_energy`** — Rata-rata energi per skala: $[1.7507,\ 3.4590,\ 4.2396,\ 4.5035,\ 4.5216,\ 4.4327,\ 4.2961,\ 4.1384,\ 3.9793]$ (puncak di skala 5: osilasi dominan sinyal acuan).
23. **`wavelet_abs_mean`** — Rata-rata $|koefisien|$ per skala: $[0.8961,\ 2.4964,\ 3.7679,\ 4.3088,\ 4.4359,\ \dots]$.
24. **`wavelet_std`** — Std koefisien per skala: $[1.5039,\ 2.3942,\ 1.9435,\ 1.3098,\ 0.8763,\ \dots]$.
25. **`wavelet_var`** — Varians $=$ std$^2$ per skala: $[2.2619,\ 5.7321,\ 3.7772,\ \dots]$ (cek: $1.5039^2 = 2.2619$ ✓).
26. **`wavelet_entropy` = 2.155207** — Energi per skala dinormalisasi jadi peluang $p_s$, lalu $-\sum p_s \ln p_s = \mathbf{2.155207}$ (entropi natural, bukan basis-2 seperti spektral).

> **Simpulan:** 19 fitur berbasis FFT/Welch dihitung manual langkah-demi-langkah dan **cocok 6 desimal** dengan TSFEL; 2 fitur cepstral + 5 wavelet dibuktikan via kode (dengan catatan keterbatasan yang jujur). Dengan ini seluruh 68 fitur (21 statistical + 21 temporal + 26 spectral) kini memiliki deskripsi, contoh manual, dan bukti TSFEL.

## 5. Kode Pembuktian Python Menggunakan TSFEL (7 Fitur Inti)

```python
import numpy as np
import tsfel

# 1. Definisi Sinyal Acuan Sederhana
x = np.array([1.0, 3.0, 2.0, 5.0, 4.0])
fs = 1

# 2. Ekstraksi Fitur Domain Spektral via TSFEL
print("=== PEMBUKTIAN FITUR DOMAIN SPECTRAL ===")
print("fundamental_frequency:", tsfel.fundamental_frequency(x, fs))
print("max_frequency        :", tsfel.max_frequency(x, fs))
print("max_power_spectrum   :", tsfel.max_power_spectrum(x, fs))
print("spectral_centroid    :", tsfel.spectral_centroid(x, fs))
print("spectral_spread      :", tsfel.spectral_spread(x, fs))
print("spectral_entropy     :", tsfel.spectral_entropy(x, fs))
print("spectral_slope       :", tsfel.spectral_slope(x, fs))
```
