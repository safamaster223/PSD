# 2.8 Konsep Dasar Statistik Deskriptif + Contoh Perhitungan

## Latar Belakang

Setelah pengumpulan data (*Data Understanding*) dan interpretasi awal konsentrasi polutan di **Kecamatan Wonoayu, Kabupaten Sidoarjo** memakai citra satelit Sentinel-5P TROPOMI, langkah berikutnya adalah analisis statistik deskriptif: memahami karakteristik, sebaran, dan anomali deret waktu harian 6 polutan ($\text{NO}_2, \text{CO}, \text{HCHO}, \text{SO}_2, \text{O}_3, \text{CH}_4$, 366 hari).

Alur *tools*: deret waktu gabungan (`wonoayu_pollutants.csv`) diunggah ke **PostgreSQL (Aiven)**, ditarik kembali ke **KNIME Analytics Platform**, lalu dihitung memakai *node* **Statistics** (rinci praktikumnya di `2.7`). Di bawah ini konsep dasar setiap metrik + rumus + contoh hitung manual memakai 5 sampel konsentrasi $\text{NO}_2$ harian (mol/m²):

$$X = [0.0001,\ 0.0003,\ 0.0002,\ 0.0005,\ 0.0004]$$

### 1. Minimum (Min) & Maximum (Max)

Nilai terkecil dan terbesar — untuk menemukan hari terbersih vs terkotor dalam setahun.

- $Min = \min(x_1, \dots, x_n)$, $Max = \max(x_1, \dots, x_n)$
- Contoh: $Min = 0.0001$, $Max = 0.0005$.

### 2. Mean (Rata-rata)

Titik pusat distribusi polutan selama periode pengamatan.

$$\mu = \frac{\sum_{i=1}^{n} x_i}{n}$$

Contoh: $\mu = \frac{0.0001+0.0003+0.0002+0.0005+0.0004}{5} = \frac{0.0015}{5} = 0.0003$.

### 3. Median (Nilai Tengah)

Nilai tengah data terurut; kebal terhadap satu hari ekstrem (misal kebakaran) yang menggeser Mean.

- $n$ ganjil: nilai posisi ke-$\frac{n+1}{2}$; $n$ genap: rata-rata dua nilai tengah.

Contoh: terurut $[0.0001, 0.0002, 0.0003, 0.0004, 0.0005]$, posisi $\frac{5+1}{2} = 3$ → Median $= 0.0003$.

### 4. Variance (Varians)

Seberapa jauh data tersebar dari rata-rata (KNIME memakai varians sampel). Besar = polusi fluktuatif.

$$s^2 = \frac{\sum_{i=1}^{n}(x_i - \mu)^2}{n-1}$$

Contoh: $s^2 = \frac{0.00000004 + 0 + 0.00000001 + 0.00000004 + 0.00000001}{4} = 0.000000025$.

### 5. Standard Deviation (Standar Deviasi)

Akar varians; satuannya sama dengan data (mol/m²) sehingga mudah dibaca.

$$s = \sqrt{s^2} = \sqrt{0.000000025} = 0.000158$$

### 6. Skewness (Kemencengan)

Simetri distribusi: $0$ = simetris; $> 0$ = menceng kanan (mayoritas hari bersih, sesekali sangat kotor — pola khas Wonoayu saat lonjakan industri/lalu lintas); $< 0$ = menceng kiri.

$$Skewness = \frac{n}{(n-1)(n-2)} \sum_{i=1}^{n}\left(\frac{x_i - \mu}{s}\right)^3$$

### 7. Kurtosis (Keruncingan)

Ekor distribusi / frekuensi outlier (KNIME memakai *excess kurtosis*): $0$ = normal (mesokurtik); $> 0$ = puncak tajam, sering lonjakan ekstrem (leptokurtik); $< 0$ = datar, stabil (platikurtik).

$$Kurtosis = \left\{\frac{n(n+1)}{(n-1)(n-2)(n-3)}\sum_{i=1}^{n}\left(\frac{x_i - \mu}{s}\right)^4\right\} - \frac{3(n-1)^2}{(n-2)(n-3)}$$
