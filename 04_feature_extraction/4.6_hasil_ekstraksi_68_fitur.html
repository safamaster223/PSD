4.6 Hasil Ekstraksi 68 Fitur#

Dokumen ini menyajikan ringkasan lengkap matriks keluaran dari 68 fitur deret waktu (time series features) hasil ekstraksi pustaka TSFEL untuk parameter kualitas udara di Kecamatan Wonoayu, Kabupaten Sidoarjo (periode 31 Agustus 2025 s.d. 31 Agustus 2026).

1. Ringkasan Distribusi 68 Fitur Berdasarkan Domain#

Pustaka TSFEL menghasilkan representasi matematis kompak yang terbagi ke dalam tiga domain utama:

┌──────────────────────────────┬──────────────────┬────────────────┐
│         Domain Fitur         │   Jumlah Fitur   │   Persentase   │
├──────────────────────────────┼──────────────────┼────────────────┤
│ 1. Domain Statistical        │     20 Fitur     │     29.4 %     │
│ 2. Domain Temporal           │     15 Fitur     │     22.1 %     │
│ 3. Domain Spectral           │     33 Fitur     │     48.5 %     │
├──────────────────────────────┼──────────────────┼────────────────┤
│            TOTAL             │     68 Fitur     │    100.0 %     │
└──────────────────────────────┴──────────────────┴────────────────┘

3. Pemanfaatan Matriks Fitur#

Matriks 68 fitur ini berhasil mereduksi 366 titik data harian mentah menjadi sebuah vektor representasi berdimensi tinggi yang padat informasi (dense representation). Fitur-fitur ini siap diintegrasikan ke berbagai algoritma pembelajaran mesin (Machine Learning) seperti Random Forest, XGBoost, atau Support Vector Machines (SVM) untuk pemodelan prediksi tingkat risiko pencemaran udara, deteksi anomali musiman, maupun klasterisasi profil lingkungan di Kecamatan Wonoayu.
