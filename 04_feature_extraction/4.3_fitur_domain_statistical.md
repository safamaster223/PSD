# 4.3 Fitur Domain Statistical

Dokumen ini memuat perincian 21 fitur dalam **Domain Statistical** dari daftar 68 fitur TSFEL yang diekstraksi untuk sinyal polutan $\text{NO}_2$ **Kecamatan Wonoayu, Kabupaten Sidoarjo**, lengkap dengan **deskripsi**, **contoh perhitungan manual**, dan **pembuktian kode Python menggunakan pustaka TSFEL**.

## 1. Konsep Domain Statistical

Domain statistik mencirikan distribusi nilai, ukuran pemusatan, dan variabilitas konsentrasi $\text{NO}_2$ tanpa memperhitungkan urutan kronologis waktu.

## 3. Perhitungan Manual & Pembuktian Kode TSFEL

Untuk membuktikan keakuratan formulasi di atas, digunakan sampel sinyal acuan sederhana $N=5$ dengan frekuensi sampling $fs = 1\text{ Hz}$:
$$X = [1.0, 3.0, 2.0, 5.0, 4.0]$$

### A. Perhitungan Manual Langkah demi Langkah

1. **`calc_min` & `calc_max`**:
   - $\text{Min} = \min(1.0, 3.0, 2.0, 5.0, 4.0) = \mathbf{1.0}$
   - $\text{Max} = \max(1.0, 3.0, 2.0, 5.0, 4.0) = \mathbf{5.0}$
2. **`calc_mean`**:
   - $\bar{x} = \frac{1.0 + 3.0 + 2.0 + 5.0 + 4.0}{5} = \frac{15.0}{5} = \mathbf{3.0}$
3. **`calc_median`**:
   - Data terurut: $[1.0, 2.0, \mathbf{3.0}, 4.0, 5.0]$ $\rightarrow$ Posisi ke-3 = $\mathbf{3.0}$
4. **`abs_energy`**:
   - $\sum x_i^2 = 1.0^2 + 3.0^2 + 2.0^2 + 5.0^2 + 4.0^2 = 1 + 9 + 4 + 25 + 16 = \mathbf{55.0}$
5. **`average_power`** ($fs=1, \Delta t = t_4 - t_0 = 4$):
   - $P_{\text{avg}} = \frac{\sum x_i^2}{t_{\text{end}} - t_{\text{start}}} = \frac{55.0}{4} = \mathbf{13.75}$
6. **`rms`**:
   - $\text{RMS} = \sqrt{\frac{1}{N}\sum x_i^2} = \sqrt{\frac{55.0}{5}} = \sqrt{11} \approx \mathbf{3.316625}$
7. **`pk_pk_distance`**:
   - $\text{Max} - \text{Min} = 5.0 - 1.0 = \mathbf{4.0}$
8. **`calc_var` & `calc_std`**:
   - $s^2 = \frac{(1-3)^2 + (3-3)^2 + (2-3)^2 + (5-3)^2 + (4-3)^2}{5-1} = \frac{4 + 0 + 1 + 4 + 1}{4} = \frac{10}{4} = \mathbf{2.0}$ (Bebas bias / sample var)
   - $s = \sqrt{2.0} \approx \mathbf{1.414214}$
9. **`interq_range`**:
   - $Q_1 = 2.0, Q_3 = 4.0 \implies \text{IQR} = 4.0 - 2.0 = \mathbf{2.0}$
10. **`mean_abs_deviation`**:
    - $\frac{\|1-3\| + \|3-3\| + \|2-3\| + \|5-3\| + \|4-3\|}{5} = \frac{2 + 0 + 1 + 2 + 1}{5} = \frac{6}{5} = \mathbf{1.2}$

### B. Kode Pembuktian Python Menggunakan TSFEL

```python
import numpy as np
import tsfel

# 1. Definisi Sinyal Acuan Sederhana
x = np.array([1.0, 3.0, 2.0, 5.0, 4.0])
fs = 1

# 2. Ekstraksi Fitur Domain Statistik via TSFEL
print("=== PEMBUKTIAN FITUR DOMAIN STATISTICAL ===")
print("calc_min             :", tsfel.calc_min(x))
print("calc_max             :", tsfel.calc_max(x))
print("calc_mean            :", tsfel.calc_mean(x))
print("calc_median          :", tsfel.calc_median(x))
print("abs_energy           :", tsfel.abs_energy(x))
print("average_power        :", tsfel.average_power(x, fs))
print("rms                  :", tsfel.rms(x))
print("pk_pk_distance       :", tsfel.pk_pk_distance(x))
print("calc_var             :", tsfel.calc_var(x))
print("calc_std             :", tsfel.calc_std(x))
print("interq_range         :", tsfel.interq_range(x))
print("mean_abs_deviation   :", tsfel.mean_abs_deviation(x))
```
