# 4.1 Persiapan Data untuk Ekstraksi

Dokumen ini menjelaskan persiapan data deret waktu polutan atmosfer bersih hasil prapemrosesan di **Kecamatan Wonoayu, Kabupaten Sidoarjo** agar memenuhi format masukan standar untuk algoritma ekstraksi fitur deret waktu.

---

## 1. Spesifikasi Masukan Ekstraksi Fitur

Algoritma ekstraksi fitur deret waktu modern—seperti **TSFEL** (*Time Series Feature Extraction Library*)—mensyaratkan sinyal input dengan spesifikasi teknis berikut:

| Parameter | Spesifikasi Input | Status Pemenuhan Data Wonoayu |
| :--- | :--- | :--- |
| **Kontinuitas Sinyal** | Bebas dari nilai kosong (`NaN` / `null`) | **Terpenuhi** (Hasil imputasi linear 366 hari) |
| **Frekuensi Waktu** | Sampling seragam ($\Delta t = \text{konstan}$) | **Terpenuhi** ($\Delta t = 1\text{ hari}$) |
| **Dimensi Sinyal** | Larik 1D (*One-Dimensional Array*) atau DataFrame | **Terpenuhi** (Vektor nilai float64 panjang 366) |
| **Periode Observasi** | 1 tahun siklus musiman penuh | **Terpenuhi** (31 Agustus 2025 – 31 Agustus 2026) |

---

## 2. Kode Penyiapan Vektor Sinyal

```python
import pandas as pd
import numpy as np

# 1. Memuat dataset bersih hasil imputasi
df_clean = pd.read_csv("data/downloads/wonoayu_pollutants_data/wonoayu_NO2.csv")
df_clean['NO2'] = df_clean['NO2'].interpolate(method='linear').bfill().ffill()

# 2. Menyiapkan vektor sinyal 1D
signal_no2 = df_clean['NO2'].values

print(f"Bentuk vektor sinyal masukan: {signal_no2.shape}")
print(f"Tipe data: {signal_no2.dtype}")
print(f"Apakah terdapat NaN: {np.isnan(signal_no2).any()}")
```

Sinyal kontinu ini siap dialirkan ke dalam modul konfigurasi TSFEL untuk mengekstraksi seluruh domain fitur matematika deret waktu.
