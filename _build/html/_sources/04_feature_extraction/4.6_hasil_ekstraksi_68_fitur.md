# 4.6 Hasil Ekstraksi 68 Fitur

## 3. Pemanfaatan Matriks Fitur

Matriks 68 fitur ini berhasil mereduksi 366 titik data harian mentah menjadi sebuah vektor representasi berdimensi tinggi yang padat informasi (*dense representation*). Fitur-fitur ini siap diintegrasikan ke berbagai algoritma pembelajaran mesin (*Machine Learning*) seperti *Random Forest*, *XGBoost*, atau *Support Vector Machines* (SVM) untuk pemodelan prediksi tingkat risiko pencemaran udara, deteksi anomali musiman, maupun klasterisasi profil lingkungan di Kecamatan Wonoayu.
