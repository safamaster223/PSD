3.1 Pembersihan Data#

Dokumen ini menjelaskan prosedur pembersihan data (Data Cleaning) pada deret waktu kualitas udara Kecamatan Wonoayu, Kabupaten Sidoarjo (periode 31 Agustus 2025 s.d. 31 Agustus 2026).

1. Tujuan Pembersihan Data#

Pembersihan data bertujuan untuk menstandarkan struktur deret waktu mentah menjadi sinyal yang teratur, konsisten secara tipe data, dan bebas dari anomali indeks waktu sebelum dilakukan imputasi dan ekstraksi fitur.

2. Prosedur dan Alur Kerja Pembersihan#

Proses pembersihan mencakup langkah-langkah sistematis berikut:

  1. Standardisasi Format Tanggal (ISO 8601):
    Mengonversi kolom waktu mentah menjadi tipe data waktu berzona (pd.to_datetime) dan memastikan zona waktu terstandarisasi ke format UTC.

  2. Penyusunan Indeks Kronologis Lengkap:
    Membuat rentang tanggal harian lengkap dari 2025-08-31 hingga 2026-08-31 (366 hari) menggunakan pd.date_range(freq='D') untuk memastikan tidak ada tanggal kalender yang terlewat (missing dates).

  3. Pemeriksaan dan Eliminasi Data Duplikat:
    Mengecek apakah terdapat lebih dari satu observasi pada tanggal yang sama. Apabila ditemukan duplikat, dilakukan agregasi rata-rata harian (groupby.mean()).

  4. Penetapan Tipe Data Numerik Presisi Tinggi:
    Memastikan kolom polutan menggunakan presisi float64 (ekuivalen dengan DOUBLE PRECISION PostgreSQL) agar nilai mikro pada orde \(10^{-5}\text{ mol/m}^2\) tetap terjaga tanpa terpotong (truncation).

3. Implementasi Kode Python#

import pandas as pd
import numpy as np

# 1. Membaca data mentah hasil pengumpulan
csv_path = "data/downloads/wonoayu_pollutants_data/wonoayu_NO2.csv"
df = pd.read_csv(csv_path)

# 2. Parsing kolom waktu dan pengurutan kronologis
df['date'] = pd.to_datetime(df['date'])
df = df.sort_values('date').reset_index(drop=True)

# 3. Membangun indeks tanggal penuh (366 hari)
full_date_range = pd.date_range(start="2025-08-31", end="2026-08-31", freq="D", tz="UTC")
df_full = pd.DataFrame({"date": full_date_range})

# 4. Penggabungan untuk memastikan keteraturan interval harian
df_cleaned = pd.merge(df_full, df, on="date", how="left")

# 5. Konversi tipe data numerik
df_cleaned['NO2'] = df_cleaned['NO2'].astype(np.float64)

print(f"Total baris setelah pembersihan indeks: {len(df_cleaned)}")
print(f"Jumlah nilai hilang sebelum imputasi: {df_cleaned['NO2'].isna().sum()}")

4. Hasil Pembersihan Data#

Hasil dari tahap pembersihan data memastikan bahwa tabel deret waktu memiliki tepat 366 baris waktu teratur (\(\Delta t = 1\text{ hari}\)), siap diproses pada tahapan penanganan outlier dan imputasi nilai kosong.
