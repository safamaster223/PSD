3.4 Validasi Data Bersih#

Dokumen ini memuat prosedur pengujian mutu, validasi integritas (Quality Assurance & Validation), serta lampiran berkas dataset deret waktu bersih hasil prapemrosesan kualitas udara Kecamatan Wonoayu, Kabupaten Sidoarjo (periode 31 Agustus 2025 s.d. 31 Agustus 2026).

1. Kriteria dan Checklist Validasi Data Bersih#

Sebelum data dialirkan ke tahapan ekstraksi fitur (BAB 4), seluruh kriteria pengujian mutu wajib terpenuhi secara menyeluruh:

No

Parameter Uji

Standar Kelulusan

Status Hasil

1

Kelengkapan Sampel (Zero Missing Value)

\(\text{Missing Value} = 0\) (\(100\%\) terisi dari 366 hari)

LULUS (0 NaN)

2

Keteraturan Kronologis (Monotonic Ascending)

Tanggal berurutan dari 2025-08-31 s.d. 2026-08-31 tanpa duplikasi atau tanggal terlewat (\(\Delta t = 1\text{ hari}\))

LULUS (366 Hari)

3

Batas Fisis Realistis (Physical Plausibility)

Konsentrasi polutan bernilai positif non-nol (\(x > 0\)) dan tidak melampaui batas fisis atmosfer troposfer

LULUS (\(x > 0\))

4

Presisi Tipe Data (Data Type Consistency)

Tipe data konsisten Float64 untuk seluruh kolom numerik

LULUS (Float64)

3. Lampiran Berkas Dataset Bersih (Clean Datasets)#

Seluruh berkas dataset yang telah divalidasi, bebas dari nilai kosong (0 missing values), dan siap digunakan untuk pemodelan maupun analisis lanjutan dapat diunduh langsung melalui tombol berikut:

A. Berkas Bersih per Polutan Individu (CSV)#

  • wonoayu_NO2_clean.csv — Deret waktu Nitrogen Dioksida bersih (\(N = 366\), Missing: \(0\)):
    Unduh wonoayu_NO2_clean.csv

  • wonoayu_CO_clean.csv — Deret waktu Karbon Monoksida bersih (\(N = 366\), Missing: \(0\)):
    Unduh wonoayu_CO_clean.csv

  • wonoayu_HCHO_clean.csv — Deret waktu Formaldehida bersih (\(N = 366\), Missing: \(0\)):
    Unduh wonoayu_HCHO_clean.csv

  • wonoayu_SO2_clean.csv — Deret waktu Sulfur Dioksida bersih (\(N = 366\), Missing: \(0\)):
    Unduh wonoayu_SO2_clean.csv

  • wonoayu_O3_clean.csv — Deret waktu Ozon Permukaan bersih (\(N = 366\), Missing: \(0\)):
    Unduh wonoayu_O3_clean.csv

  • wonoayu_CH4_clean.csv — Deret waktu Metana bersih (\(N = 366\), Missing: \(0\)):
    Unduh wonoayu_CH4_clean.csv

B. Berkas Bersih Gabungan Seluruh Polutan (Multi-Parameter CSV)#

  • wonoayu_pollutants_clean.csv — Tabel gabungan keenam parameter polutan atmosfer bersih (\(366\text{ baris} \times 7\text{ kolom}\)):
    Unduh wonoayu_pollutants_clean.csv (Lengkap)

4. Cara Membaca Data Bersih dengan Python#

import pandas as pd

# Membaca dataset multi-parameter polutan bersih Kecamatan Wonoayu
url_clean = "data/downloads/wonoayu_clean_data/wonoayu_pollutants_clean.csv"
df_clean = pd.read_csv(url_clean, parse_dates=['date'])

print(df_clean.info())
print("\nJumlah Nilai Kosong per Kolom:")
print(df_clean.isna().sum())
print("\nPratinjau 5 Baris Pertama:")
print(df_clean.head())
