5.5 Implementasi Workflow KNIME Analytics Platform#

Dokumen ini menjelaskan rancangan dan konfigurasi workflow KNIME Analytics Platform untuk mereplikasi tahapan Reduksi Dimensi PCA (1 - 37 Komponen) dan K-Means Clustering secara visual tanpa kode untuk polutan individu (\(\text{NO}_2\), \(\text{SO}_2\), \(\text{CO}\)) dan gabungannya.

1. Arsitektur Workflow KNIME Analytics Platform#

Alur pemrosesan data pada kanvas KNIME Analytics Platform dirancang sebagai berikut:

┌─────────────────┐      ┌─────────────────┐      ┌─────────────────┐
│   CSV Reader    │ ───► │   Normalizer    │ ───► │   PCA Compute   │
│ (68 Fitur TSFEL)│      │  (Z-Score Norm) │      │  (37 Komponen)  │
└─────────────────┘      └─────────────────┘      └────────┬────────┘
                                                           │
                                                           ▼
┌─────────────────┐      ┌─────────────────┐      ┌─────────────────┐
│  Scatter Plot   │ ◄─── │  Color Manager  │ ◄─── │     k-Means     │
│  (Visualisasi)  │      │(Cluster Colors) │      │  (K=4 Clusters) │
└─────────────────┘      └─────────────────┘      └─────────────────┘

2. Panduan Setup & Konfigurasi Setiap Node KNIME#

A. Node CSV Reader#

  • Fungsi: Memuat berkas dataset matriks 68 fitur TSFEL (wonoayu_pollutants.csv atau matriks multi-fitur \(\text{NO}_2, \text{SO}_2, \text{CO}\)).

  • Pengaturan:

    1. Tentukan lokasi file CSV.

    2. Centang Has Column Header.

    3. Pastikan seluruh kolom terdeteksi sebagai tipe data Number (double).

B. Node Normalizer#

  • Fungsi: Mengubah skala seluruh 68 fitur ke rentang terstandar (Z-Score Normalization / Mean=0, Std=1).

  • Pengaturan:

    1. Masukkan kolom numerik pada daftar Include Columns.

    2. Pilih metode Z-Score Normalization (Gaussian).

C. Node PCA Compute & PCA Apply#

  • Fungsi: Menghitung matriks kovarians dan memproyeksikan data ke 37 Komponen Utama (PCA 1 - PCA 37) untuk multi-polutan atau komponen utama individual.

  • Pengaturan:

    1. Pilih target reduksi berbasis jumlah komponen: 37 Komponen (untuk combined) atau komponen individual.

    2. Centang opsi Output Cumulative Variance.

D. Node k-Means#

  • Fungsi: Menjalankan algoritma K-Means Clustering pada data hasil transformasi 37 komponen PCA.

  • Pengaturan:

    1. Set Number of Clusters (\(k\)) = 4 (untuk Combined 3 Polutan) atau 3 (untuk polutan individu).

    2. Set Max number of iterations = 100.

    3. Set Initialization method = k-Means++ / Random dengan fixed seed.

E. Node Color Manager & Scatter Plot#

  • Fungsi: Memberikan skema warna unik untuk masing-masing klaster dan menampilkan sebaran data 2D pada sumbu PCA_1 vs PCA_2.
