4.4 Fitur Domain Temporal#

Dokumen ini memuat perincian 21 fitur dalam Domain Temporal & Dinamika Fraktal dari daftar 68 fitur TSFEL yang diekstraksi untuk sinyal polutan \(\text{NO}_2\) Kecamatan Wonoayu, Kabupaten Sidoarjo, lengkap dengan deskripsi, contoh perhitungan manual, dan pembuktian kode Python menggunakan pustaka TSFEL.

1. Konsep Domain Temporal & Kompleksitas Sinyal#

Domain temporal mengevaluasi sifat-sifat sinyal deret waktu yang bergantung pada keterurutan kronologis, kontinuitas waktu, kecepatan transisi, serta derajat keteraturan dan kompleksitas non-linear (fractal dimensions).

3. Perhitungan Manual & Pembuktian Kode TSFEL#

Untuk membuktikan keakuratan formulasi di atas, digunakan sampel sinyal acuan sederhana \(N=5\) dengan frekuensi sampling \(fs = 1\text{ Hz}\) dan sumbu waktu \(t = [0, 1, 2, 3, 4]\): $\(X = [1.0, 3.0, 2.0, 5.0, 4.0]\)$

A. Perhitungan Manual Langkah demi Langkah#

  1. Selisih Harian (\(\Delta X = x_{t} - x_{t-1}\)):

    • \(\Delta X = [3-1, 2-3, 5-2, 4-5] = [2.0, -1.0, 3.0, -1.0]\) (\(N-1 = 4\) elemen)

    • Mutlak selisih \(|\Delta X| = [2.0, 1.0, 3.0, 1.0]\)

  2. mean_diff:

    • \(\bar{\Delta X} = \frac{2.0 + (-1.0) + 3.0 + (-1.0)}{4} = \frac{3.0}{4} = \mathbf{0.75}\)

  3. mean_abs_diff:

    • \(\overline{|\Delta X|} = \frac{2.0 + 1.0 + 3.0 + 1.0}{4} = \frac{7.0}{4} = \mathbf{1.75}\)

  4. sum_abs_diff:

    • \(\sum |\Delta X| = 2.0 + 1.0 + 3.0 + 1.0 = \mathbf{7.0}\)

  5. median_diff:

    • Data selisih terurut: \([-1.0, -1.0, 2.0, 3.0] \implies \text{Median} = \frac{-1.0 + 2.0}{2} = \mathbf{0.5}\)

  6. median_abs_diff:

    • Data mutlak terurut: \([1.0, 1.0, 2.0, 3.0] \implies \text{Median} = \frac{1.0 + 2.0}{2} = \mathbf{1.5}\)

  7. auc (Area Under Curve - Integrasi Trapesium):

    • Trapesium 1 (\(t=0 \to 1\)): \(\frac{1.0 + 3.0}{2} \times 1 = 2.0\)

    • Trapesium 2 (\(t=1 \to 2\)): \(\frac{3.0 + 2.0}{2} \times 1 = 2.5\)

    • Trapesium 3 (\(t=2 \to 3\)): \(\frac{2.0 + 5.0}{2} \times 1 = 3.5\)

    • Trapesium 4 (\(t=3 \to 4\)): \(\frac{5.0 + 4.0}{2} \times 1 = 4.5\)

    • Total \(\text{AUC} = 2.0 + 2.5 + 3.5 + 4.5 = \mathbf{12.5}\)

  8. slope (Kemiringan Regresi Linier Terhadap Waktu \(t = [0, 1, 2, 3, 4]\)):

    • Rata-rata \(\bar{t} = 2.0\), \(\bar{x} = 3.0\)

    • \(\text{Cov}(t, x) = \sum (t_i - \bar{t})(x_i - \bar{x}) = (-2)(-2) + (-1)(0) + (0)(-1) + (1)(2) + (2)(1) = 4 + 0 + 0 + 2 + 2 = 8.0\)

    • \(\text{Var}(t) = \sum (t_i - \bar{t})^2 = (-2)^2 + (-1)^2 + 0^2 + 1^2 + 2^2 = 4 + 1 + 0 + 1 + 4 = 10.0\)

    • \(\text{Slope} = \frac{\text{Cov}(t, x)}{\text{Var}(t)} = \frac{8.0}{10.0} = \mathbf{0.8}\)

  9. calc_centroid (Titik Berat Temporal Berbasis Energi \(x^2\)):

    • Sinyal Energi \(X^2 = [1, 9, 4, 25, 16] \implies \sum X^2 = 55.0\)

    • Momen Waktu Energi \(= 0(1) + 1(9) + 2(4) + 3(25) + 4(16) = 0 + 9 + 8 + 75 + 64 = 156.0\)

    • \(\text{Centroid} = \frac{156.0}{55.0} = \frac{156}{55} \approx \mathbf{2.836364}\)

  10. distance (Panjang Lintasan kurva sinyal \(d = \sum \sqrt{\Delta t^2 + \Delta x^2}\)):

    • Segmen 1 (\(1 \to 3\)): \(\sqrt{1^2 + 2^2} = \sqrt{5} \approx 2.236068\)

    • Segmen 2 (\(3 \to 2\)): \(\sqrt{1^2 + (-1)^2} = \sqrt{2} \approx 1.414214\)

    • Segmen 3 (\(2 \to 5\)): \(\sqrt{1^2 + 3^2} = \sqrt{10} \approx 3.162278\)

    • Segmen 4 (\(5 \to 4\)): \(\sqrt{1^2 + (-1)^2} = \sqrt{2} \approx 1.414214\)

    • Total \(\text{Distance} = \sqrt{5} + \sqrt{2} + \sqrt{10} + \sqrt{2} \approx \mathbf{8.226773}\)

  11. positive_turning & negative_turning (Titik Belok Puncak & Lembah TSFEL):

    • Vektor turunan \(\Delta X = [2, -1, 3, -1]\)

    • Puncak (Positive Turning): Transisi \(\Delta X > 0 \to \Delta X < 0\) terjadi pada 2 titik (\([2, -1]\) dan \([3, -1]\)) \(\rightarrow \mathbf{2}\)

    • Lembah (Negative Turning): Transisi \(\Delta X < 0 \to \Delta X > 0\) terjadi pada 1 titik (\([-1, 3]\)) \(\rightarrow \mathbf{1}\)

B. Kode Pembuktian Python Menggunakan TSFEL#

import numpy as np
import tsfel

# 1. Definisi Sinyal Acuan Sederhana
x = np.array([1.0, 3.0, 2.0, 5.0, 4.0])
fs = 1

# 2. Ekstraksi Fitur Domain Temporal via TSFEL
print("=== PEMBUKTIAN FITUR DOMAIN TEMPORAL ===")
print("mean_diff          :", tsfel.mean_diff(x))
print("mean_abs_diff      :", tsfel.mean_abs_diff(x))
print("sum_abs_diff       :", tsfel.sum_abs_diff(x))
print("median_diff        :", tsfel.median_diff(x))
print("median_abs_diff    :", tsfel.median_abs_diff(x))
print("auc                :", tsfel.auc(x, fs))
print("slope              :", tsfel.slope(x))
print("calc_centroid      :", tsfel.calc_centroid(x, fs))
print("distance           :", tsfel.distance(x))
print("positive_turning   :", tsfel.positive_turning(x))
print("negative_turning   :", tsfel.negative_turning(x))
